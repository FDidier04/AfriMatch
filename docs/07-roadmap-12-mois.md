# Roadmap produit 12 mois

## Mois 1-2 : cadrage et socle

- finaliser positionnement et charte ;
- definir le modele de donnees ;
- creer backend Symfony et frontend Vue ;
- mettre en place auth JWT ;
- creer pages publiques principales ;
- creer registre RGPD initial.

## Mois 3-4 : MVP projet

- creation de projet ;
- moderation admin ;
- liste et fiche projet ;
- filtres pays, secteur, besoin, stade ;
- dashboard porteur ;
- upload ou liens vers documents ;
- publication des premiers projets verifies.

## Mois 5-6 : partenaires et contacts

- profils partenaires ;
- dashboard partenaire ;
- demandes de contact ;
- sauvegarde de projets ;
- messagerie simple ;
- notifications email de base.

## Mois 7-8 : matching

- moteur de score 0-100 ;
- recommandations personnalisees ;
- raisons de matching ;
- preferences partenaire ;
- statistiques de matching ;
- amelioration des filtres.

## Mois 9-10 : monetisation

- plans gratuit et premium ;
- boosts de projets ;
- visibilite sponsorisee ;
- quotas de demandes de contact ;
- premieres offres institutionnelles.

## Mois 11-12 : croissance et confiance

- badges de verification avances ;
- success stories ;
- analytics plus fins ;
- newsletters personnalisees ;
- partenariats avec incubateurs et reseaux ;
- preparation extension anglophone ou panafricaine.
