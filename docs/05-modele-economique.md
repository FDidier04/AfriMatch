# Modele economique

## Offre gratuite

Pour porteurs :
- creation d'un compte ;
- soumission d'un projet ;
- publication apres moderation ;
- reception limitee de demandes de contact ;
- statistiques simples.

Pour partenaires :
- consultation des projets publics ;
- filtres de base ;
- sauvegardes limitees ;
- demandes de contact limitees.

## Premium porteur

Benefices :
- mise en avant moderee ;
- statistiques avancees ;
- documents enrichis ;
- priorite de moderation ;
- recommandations de partenaires ;
- badge profil complet.

Facturation possible :
- abonnement mensuel ;
- forfait trimestriel ;
- pack projet.

## Premium partenaire

Benefices :
- filtres avances ;
- alertes personnalisees ;
- matching prioritaire ;
- demandes de contact augmentees ;
- export de fiches selectionnees ;
- espace organisation multi-utilisateurs.

## Revenus additionnels

- boost de projets ;
- visibilite sponsorisee clairement identifiee ;
- pages partenaires institutionnels ;
- rapports sectoriels anonymises ;
- accompagnement a la preparation de dossier ;
- abonnement incubateurs, fonds, ONG ou entreprises.

## Principes de confiance

- la visibilite sponsorisee ne doit pas remplacer la verification ;
- les projets sponsorises doivent etre marques comme tels ;
- les contacts sensibles doivent rester controles par les utilisateurs ;
- pas de commission automatique sur levee de fonds au MVP sans cadre juridique solide.
