# Identite de marque Afrimatch

## Essence

Afrimatch est une marque de confiance, d'opportunite et de mouvement. Elle doit parler aux entrepreneurs africains ambitieux comme aux partenaires institutionnels et prives qui cherchent des projets serieux.

## Promesse

Connecter les projets africains deja en marche avec les partenaires capables d'accelerer leur impact.

## Ton

- professionnel ;
- direct ;
- optimiste ;
- concret ;
- accessible ;
- ancre dans les realites africaines.

## Messages cles

- Des projets reels, pas seulement des idees.
- Trouvez des partenaires adaptes a votre stade.
- Decouvrez des opportunites qualifiees en Afrique francophone.
- Passez du contact aleatoire a la mise en relation structuree.

## Taglines possibles

- `Les bons partenaires pour les projets africains en mouvement.`
- `Connecter les projets reels aux partenaires utiles.`
- `La marketplace des partenariats africains.`
- `Projets verifies. Partenaires qualifies.`

## Direction visuelle

L'interface doit etre claire et professionnelle, avec une energie africaine contemporaine sans tomber dans le folklore. Elle peut utiliser :
- une couleur principale verte ou bleu profond pour la confiance ;
- un accent chaud pour les actions importantes ;
- beaucoup d'espace blanc ;
- des cartes compactes ;
- des badges lisibles ;
- des visuels de projets reels.

## Noms de plans

- Gratuit ;
- Pro ;
- Boost ;
- Institution.

## Microcopy

CTA :
- Publier un projet ;
- Devenir partenaire ;
- Voir les projets ;
- Contacter le porteur ;
- Sauvegarder ;
- Voir mes matches.

Badges :
- Projet verifie ;
- En traction ;
- Recherche partenaire ;
- Impact social ;
- Besoin financement ;
- Besoin distribution.
